# KeyboneNetCross

Place the content of the [KeyboneNetCross](https://drive.google.com/drive/folders/1Vggo3RTWlzEmCd50pi6vApICekawpDeA?usp=drive_link) folder in this directory, structured as follows:
```
data/KeyboneNetCross/
├── annotations/
├── geodesics/
├── mesh/
├── pcds/
├── splits/
└── synsetoffset2category.txt
```

The `geodesics` folder (~4 GB) is optional, as missing geodesic distances are computed and cached automatically at the first evaluation.
